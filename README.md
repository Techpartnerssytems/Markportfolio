## ⚙️ Serverless Backend Architecture (`Appscript/`)

The contact form in `index.html` is powered by a zero-cost, serverless **Google Apps Script + Google Sheets + Gmail** pipeline:

```text
0777. Porfolio - Mark/
├── index.html                        # Main SPA Portfolio & SEO Schema
├── .css                              # Custom Design System & Responsive Grid
├── site.webmanifest                  # PWA Manifest & App Icons
├── 01. Images/                       # Mark Dalumpines Portraits, Avatar & Partner Logos
├── 02. Images/                       # Project Showcases & Client Testimonial Photos
├── 03. Images Icon/                  # Brand & Channel Icons
├── 04. Certificates/                 # 15 Verified Credentials & Course Certificates
├── js/
│   ├── constellation.js              # Cyan & Bronze Particle Canvas Engine
│   ├── Collaboration.js              # Collaboration Marquee & Modal Logic
│   └── main.js                       # Core UI Interactivity
└── Appscript/
    ├── code.gs                       # Google Sheets Ingestion & Dual Gmail Dispatcher
    ├── ReceivedEmailMark.html        # Admin Lead Alert Template (-> Dtpsystems2026@gmail.com)
    └── SendEmailLead.html            # Client Auto-Responder Template (24-48h SLA + Copy of Answers)
```

### **How the Contact Automation Works:**
1. **Form Submission**: Prospect submits project scope in Column 1 of the Contact section.
2. **Database Sync**: `Appscript/code.gs` parses the payload and appends a timestamped record to the `Inquiries` tab in Google Sheets.
3. **Instant Admin Alert (`ReceivedEmailMark.html`)**: Dispatches a formatted white-and-dark-blue HTML summary with all prospect answers and 1-click reply buttons to `Dtpsystems2026@gmail.com`.
4. **Instant Client Confirmation (`SendEmailLead.html`)**: Sends a personalized confirmation email from **Mark Dalumpines (AI Automation Specialist & GHL Expert)** with a copy of their submission and a **24–48 business hours** response commitment.
